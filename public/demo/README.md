3. **Ngăn Kéo Lời Thoại Thuyết Trình Thông Minh (Speaker Cheatsheet Drawer)**:
   - Nhấn phím `N` hoặc bấm nút **"Lời Thoại (N)"** ở góc trên bên phải để mở ngăn kéo ghi chú.
   - Cung cấp toàn bộ **Lời nói mẫu chi tiết bằng tiếng Việt** cho từng slide: Bạn chỉ cần nhìn vào là biết chính xác từng câu mở đầu, trọng tâm cần nhấn mạnh, và cách giải thích trôi chảy.
   - Tích hợp sẵn **Bộ câu hỏi phản biện của Thầy Cô & Hướng dẫn trả lời** cho từng slide, giúp bạn tự tin làm chủ buổi bảo vệ.

### 2. Các Phím Tắt Điều Khiển

| Phím Tắt | Chức Năng |
| :---: | :--- |
| `→` / `Space` / `PageDown` | Chuyển sang Slide tiếp theo |
| `←` / `PageUp` | Quay lại Slide trước đó |
| `N` | Bật / Tắt Ngăn kéo Lời thoại thuyết trình (Speaker Notes Drawer) |
| `F` | Bật / Tắt chế độ Toàn màn hình (Fullscreen) |
| `Home` | Về ngay Slide đầu tiên (Slide 1) |
| `End` | Nhảy đến Slide cuối cùng (Slide 10) |
| `1` - `9`, `0` | Nhảy trực tiếp đến Slide từ 1 đến 10 |
| `ESC` | Đóng ngăn kéo lời thoại hoặc thoát toàn màn hình |
